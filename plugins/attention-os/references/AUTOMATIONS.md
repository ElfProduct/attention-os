# Scheduled routines

Onboarding uses Codex scheduled tasks rather than installing an operating-system
daemon. Times are examples and must be adapted to the user's timezone and life.

## Morning briefing

Recommended: each morning after the first reliable source refresh. Invoke the
Morning Briefing skill, read private memory, verify current Calendar and tasks,
and deliver one source-labelled plan. If video is enabled, render it privately
and publish only after media verification.

## Evening reconciliation

Recommended: near the end of the local day. Invoke Daily Reconciliation across
the full day, state source gaps, save the review, then invoke Memory Compiler for
ready lifecycle jobs.

## Weekly review

Recommended: once per week after the final daily reconciliation. Compare the
same declared goals and outcome categories across the whole week. Do not produce
a verdict from a partial interval and do not notify when the run has no actionable
change.

Scheduled prompts must not silently send messages, modify external systems,
publish memory, spend money, or broaden connector permissions.
