# Product contract

Attention OS is a local-first founder operating system delivered as a Codex
plugin. It helps a person preserve durable context, choose a goal-directed focus,
and reconcile intention with evidence.

## The products

- **Private memory:** human-readable Markdown with local Git provenance.
- **Founder Coach:** decision-first coaching grounded in declared goals.
- **Memory Review:** a read-only local view plus source-aware correction flow.
- **Daily Reconciliation:** a complete-window evidence review.
- **Evening Review:** a short human reflection.
- **Morning Briefing:** a text or optional narrated Remotion briefing.
- **Content Scout:** a small, current, goal-relevant information feed.

## Boundaries

Codex supplies the conversational shell, model, task lifecycle, plugin runtime,
connectors, and scheduled-task interface. This repository supplies opinionated
instructions, lifecycle capture, private storage contracts, templates, and
product workflows. It does not contain a model, cloud backend, public social
network, or the creator's personal memory.

External actions always retain their normal permission boundary. Memory can
inform action; it cannot authorize it.
