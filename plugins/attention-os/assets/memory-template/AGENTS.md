# Private memory operating rules

This repository is the user's canonical, human-readable memory. It belongs to
{{NAME}} and is private by default.

## Retrieval

1. Read `index.md` as the catalogue.
2. Open only pages relevant to the current request.
3. Prefer fresh systems of record for volatile facts.
4. Treat explicit declarations and corrections as stronger evidence than
   observed behaviour.

## Writing

- Store durable understanding, decisions, corrections, commitments, and useful
  provenance—not full transcripts or indiscriminate activity logs.
- Separate fact, declaration, observation, inference, recommendation, and
  unknowns.
- Make one coherent topic change at a time and commit it to local Git.
- Correct mistakes with a new compensating change. Do not rewrite Git history.
- Never store credentials, private keys, authentication cookies, raw private
  messages, or sensitive third-party detail that is not required.
- Never publish this repository or add a remote without explicit user approval.

Memory can inform advice. It cannot authorize external messages, purchases,
calendar changes, task changes, or other commitments.
