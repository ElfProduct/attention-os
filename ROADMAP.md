# Roadmap

## v0.1 — Codex-native alpha

- Installable plugin with lifecycle hooks and eight focused skills.
- Guided private-memory setup with local Git provenance.
- Founder coaching, Memory Review, daily/evening reviews, Morning Briefing, and
  Content Scout contracts.
- Scheduled-task onboarding and optional connector/voice authorization.
- Video-first README and reproducible Remotion source.

## Before calling it frictionless

- Test from a genuinely clean Codex account and machine.
- Submit to the universal plugin directory so install is one click rather than a
  marketplace-add command followed by install.
- Add onboarding recovery, update/migration, uninstall, and connector-permission
  tests.
- Ship and verify a reusable Morning Briefing render adapter across supported
  machines.
- Run privacy, prompt-injection, secret-handling, and destructive-action audits.

## Later experiments

- Team-shared memory with explicit ownership and access policy.
- Cross-harness signed agent cards and bilateral delegation receipts.
- Federated discovery and verified-outcome reputation.
- Governed agent teams only after adversarial safety evaluation.

See `AGENT_SOCIAL_LAYER.md` in the plugin references for the speculative thesis.
